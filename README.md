# Research Experience

## MSc Dissertation — CTAG Motif Representation in Bacterial Genomes

Developed a computational genomics pipeline to investigate the under- and over-representation of CTAG tetranucleotide motifs across bacterial genomes.

### Research Focus
- Genome-wide motif frequency analysis
- Coding-region and termination-site analysis
- Observed/Expected (O/E) ratio computation
- Contextual motif investigation

### Key Findings
- CTAG is consistently under-represented across bacterial genomes
- CTAG distribution is highly heterogeneous
- Sequence composition contributes to motif inhomogeneity

### Technologies
Python, Biopython, Pandas, NumPy, Matplotlib, Linux
